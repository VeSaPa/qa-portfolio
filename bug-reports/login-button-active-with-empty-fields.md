# Bug Report: 
Login button is enabled when email and password fields are empty

## Environment
Browser:
Chrome
OS:
macOS
Environment: 
Test environment

## Description
The Login button is enabled even when the email and password fields are empty.

## Steps to reproduce
1. Open the login page
2. Leave the email field empty
3. Leave the password field empty
4. Observe the Login button

## Expected result
The Login button should be disabled until the required fields are filled.

## Actual result
The Login button is enabled even when the email and password fields are empty.

## Severity
Meduim

## Priority
Medium

# Bug Report: Login button active with empty fields

## Environment
Browser: Chrome
OS: macOS
Environment: Test environment

## Description
The login button is active even when the email and password fields are empty.

## Stepts to reproduce
1. Open the login page
2. Leave email field empty
3. Leave password field empty
4. Observe the login button

## Expected result
The login button should be disabled until required fields are filled.

## Actual result
The login button is active even when the fields are empty.

## Severity
Meduim

## Priority
Medium

# Bug Report: The `Forgot Password` link does not redirect to the reset password page

## Environment
Browser:
Chrome
OS:
macOS
Environment:
Test environment

## Description
The `Forgot Password` link does not redirect the user to the reset password page.

## Steps to reproduce
1. Open the login page
2. Click the `Forgot Password` link

## Expected Result
The user is redirected to the password reset page.

## Actual Result
The user is not redirected to the password reset page.

## Severity
High

## Priority
High

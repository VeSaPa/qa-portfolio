# Bug Report: Confirm Password field does not mask entered characters

## Environment
Browser: 
Chrome
OS:
macOS
Environment:
Test environment

## Description
The Confirm Password field in the registration form does not mask entered characters.

## Steps to reproduce
1. Open the registration page
2. Enter any email address in the email field
3. Enter any password in the password field
4. Enter any password in the confirm password field
5. Observe the confirm password field

## Expected result
Entered characters in the confirm password field are masked.

## Actual result
Entered characters in the confirm password field are not masked.

## Severity
Medium

## Priority
High
